# Met3:
Поля, которые послал: name\
Поля в ответе на PUT: id, name\
Поля в ответе на PATCH: id, name, username, email, address, phone, website, company\
Поля, которых не посылал, но они пришли:  id, username, email, address, phone, website, company\
Вывод (слияние или эхо): песочница показывает разные поведения на запросы:\
PATCH - слияние, PUT - эхо

# Met4.
Статус DELETE: 200 OK\
Тело DELETE: {}\
Теория разрешает успеху DELETE: 200 OK или 204 No Content\
Статус GET /posts/3 после удаления: 200 OK\
Хватает ли одного статуса для веры: Нет\
Чего не хватает для веры: Контрольного чтения (контрольный GET должен вернуть 404)

# Met5.
PUT, отправка 1: 200 OK, {"id": 1, "name": "Dup"}\
PUT, отправка 2: 200 OK, {"id": 1, "name": "Dup"}\
Ответы PUT совпали: Да\
POST, отправка 1, id: 101\
POST, отправка 2, id: 101 (в реальном API были бы 101 и 102)\
id совпали: Да (из-за симулятора), но по стандарту создаются новые записи\
Вывод: Метод PUT — идемпотентен, POST — не идемпотентен.

# Met6
| Метод | Безопасен? | Идемпотентен? | Обоснование |
| :--- | :---: | :---: | :--- |
| **GET** | Да | Да | Повторный вызов GET /users/1 не меняет данные на сервере и возвращает один и тот же результат (проверено личным вызовом). |
| **POST** | Нет | Нет | В Met1/Met5 отправка запроса приводит к созданию новой записи; повтор POST с тем же телом плодит дубликаты ресурса. |
| **PUT** | Нет | Да | В Met5 повторные запросы PUT /users/1 перезаписывают ресурс тем же состоянием, итоговый результат на сервере одинаков. |
| **PATCH** | Нет | Не всегда | Выведено из теории 2.3: обновление конкретного поля идемпотентно (name="Ada"), но операции вроде инкремента счетчика — нет. |
| **DELETE** | Нет | Да | Выведено из теории 2.3 и Met4: повторный вызов удаляет уже отсутствующий ресурс, но итоговое состояние системы не меняется. |

**Вопрос к себе:**
Сколько строк таблицы заполнено твоими наблюдениями, а сколько теорией?\
Ответ: Три строки (GET, POST, PUT) заполнены на основе личных практических наблюдений из задач Met1–Met5, а две строки (PATCH, DELETE) — выведены из теории\
раздела 2.3.
